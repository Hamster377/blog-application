# Blogify - Blog Application

A responsive blog application developed using HTML, CSS and JavaScript.

## Features

- Responsive design
- User registration
- User login
- Dashboard
- Create blog posts
- Display blog posts
- Delete blog posts
- Logout functionality
- Form validation
- Local storage for data management

## Technologies Used

- HTML5
- CSS3
- JavaScript
- LocalStorage

## Pages

1. Home
2. Login
3. Register
4. Dashboard
5. Create Blog

## How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Open `index.html` in a web browser.

## Project Purpose

This project was developed as part of the Codomax Digital internship to demonstrate fundamental frontend development skills using HTML, CSS and JavaScript.
